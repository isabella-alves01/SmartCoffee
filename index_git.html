Comendos Git

git init - Esse comendo cria o repositorio Git Local

git status - checar status do repositorio

git add - ira adcionar esse aequivo em processo de envio

git commit - Representar a confirmação do processo ou seja, enviar

git log - mostrar o log ou registro das evoluçoes feitas no reprositório

git branch - branches - representa uma linha de desenvolvimento

Criando repositório

Preciso do meu repositório criado no github para dar inicio as configurações de publicação do projeto

Por que não criar o README.md?

por que nosso projeto já possui um histórico. Manter o remoto vazio simplifica a conexão e evita históricos diferentes.

git remote add origin - adicionar o repositório remoto

git remote -v - vizualizar conexão remote git

O que é Origin?

É um nome convencional dados ao repositorio remoto

git push - envia a branch main, usa o remoto origin configura o acompanhamento entre branch local e remote

git push -u origin main
